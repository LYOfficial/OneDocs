# 🧠 分析功能

OneDocs 提供四种专业分析模式，针对不同类型的文档进行智能解析，每种模式都有专属的提示词策略和输出结构。

---

## 功能概览

| 功能 | 图标 | 适用场景 | 输出结构 |
|------|------|---------|----------|
| **要闻概览** | 📰 | 新闻报道、资讯文章 | 要闻速览 + 深度透视 |
| **罗森析数** | 📊 | 数据报告、统计表格 | 分析结论 + 数据详情 |
| **理工速知** | 🔬 | 理工科课件、教材 | 基础知识 + 典型例题 |
| **文采丰呈** | 📚 | 文科课件、人文资料 | 核心解读 + 思辨拓展 |

---

## 要闻概览

> 📰 新闻要点梳理专家

适用于各类新闻报道、资讯文章、时事评论等文档。

### 输出结构

**第一部分：要闻速览**
- 一句话摘要（100字内）
- 核心要素表（5W1H：Who/What/When/Where/Why/How）
- 影响评级

**第二部分：深度透视**
- 背景回溯：事件来龙去脉
- 各方立场：不同利益相关方的观点
- 未来展望：事件可能的发展方向

### 适用文档示例

- 每日新闻简报
- 行业分析报告
- 政策解读文章
- 财经资讯

---

## 罗森析数

> 📊 数据内容分析专家

适用于包含大量数据和统计信息的文档，如商业报告、财务报表、市场调研等。

### 输出结构

**第一部分：分析结论**
- 核心发现：3-5句话概括最重要结论
- 关键指标：核心 KPIs 及变化
- 行动建议：具体可落地的建议

**第二部分：数据详情**
- 趋势分析：数据随时间的变化趋势
- 结构分析：数据的组成和分布
- 异常监测：异常数据点的识别和说明

### 适用文档示例

- 季度/年度财务报告
- 市场调研数据
- 行业统计年鉴
- 用户增长分析报告

---

## 理工速知

> 🔬 理工课件整理专家

适用于理工科课件、教材、学术论文等文档，生成类似学霸笔记的结构化复习资料。

### 输出结构

**第一部分：基础知识**
- 概念定义（加粗术语）
- 公式附中文说明
- 图片标签引用（`[[IMG_P页码_序号]]`）
- 图表转流程图或 Markdown 表格

**第二部分：典型例题**
- 完整复现题目和解答
- 详细计算步骤
- 结论高亮（**【最终结论】**）

### 格式特点

- 行内公式用 `$x$`，块级公式用 `$$公式$$`
- 重要概念加粗，专业术语标注英文
- 支持 LaTeX 数学公式渲染

### 适用文档示例

- 高等数学课件
- 物理学讲义
- 计算机科学教材
- 工程技术文档

---

## 文采丰呈

> 📚 文科课件整理专家

适用于人文学科课件、文学评论、哲学论述等文档，风格博学多才、富有洞察力。

### 输出结构

**第一部分：核心解读**
- 背景还原：作者生平、创作背景、时代特征
- 义理阐释：核心思想、概念辨析
- 文本分析：修辞意象或论证逻辑

**第二部分：思辨拓展**
- 比较视野：横向对比、纵向演变
- 当代价值：现实启示、批判性思考

### 适用文档示例

- 文学作品赏析
- 历史学讲义
- 哲学导论课件
- 艺术史资料

---

## 选择建议

不确定选哪个功能？参考以下决策流程：

```
你的文档是什么类型？
│
├─ 新闻/资讯类 ──────────→ 要闻概览 📰
│
├─ 数据/报表类 ──────────→ 罗森析数 📊
│
├─ 理工科学习资料 ────────→ 理工速知 🔬
│
├─ 文科学习资料 ──────────→ 文采丰呈 📚
│
└─ 不确定 ──→ 根据文档主要内容选择最接近的模式
```

> 💡 如果文档内容混合了多种类型，建议选择占比最大的内容类型对应的分析模式。
