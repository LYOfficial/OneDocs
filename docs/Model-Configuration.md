## 配置步骤

### 1. 进入模型设置

点击顶部导航栏「**设置**」→ 左侧选择「**模型**」

### 2. 选择供应商

在供应商列表中选择你拥有的模型供应商。

### 3. 填写配置

| 字段 | 必填 | 说明 |
|------|------|------|
| **API Key** | ✅ | 供应商提供的 API 密钥 |
| **Base URL** | ❌ | 默认为官方地址，使用第三方服务时需替换 |
| **模型** | ✅ | 选择具体使用的模型 |

### 4. 保存配置

填写完毕后点击「**保存**」，配置会自动持久化到本地。

## 添加自定义模型

如果供应商列表中没有你需要的模型，可以手动添加：

1. 在模型设置页面，找到「**自定义模型**」区域
2. 输入模型名称（如 `my-custom-model`）
3. 点击添加

> 💡 自定义模型名称需要与 API 供应商支持的模型 ID 一致。

## 常见问题

### Q: 模型报错 "API Key 无效"？

- 检查 API Key 是否正确复制（注意前后空格）
- 确认 API Key 对应的供应商选择正确
- 部分 API Key 有额度限制，确认账户有余额

### Q: 分析结果质量不好？

- 尝试切换更高级的模型（如从 GPT-3.5 升级到 GPT-4o）
- 开启「格式复查」功能（设置 → 通用）
- 配置 RAG 嵌入模型提升分析质量

### Q: 免费模型无法使用？

免费模型额度有限，可能暂时不可用。建议：
- 稍后重试
- 切换其他免费模型
- 使用付费模型（DeepSeek 价格极低）
