# 📋 结果处理

分析完成后，OneDocs 提供多种方式查看和处理分析结果。

---

## 查看结果

分析完成后，结果会自动展示在右侧面板中。

### 渲染模式

默认的查看模式，将 Markdown 渲染为格式化的富文本：

- 支持标题、列表、表格等 Markdown 语法
- 支持 LaTeX 数学公式渲染（使用 KaTeX）
- 支持图片标签引用

### 源码模式

查看原始 Markdown 文本，适合：

- 复制到其他 Markdown 编辑器
- 检查格式和公式语法
- 进行二次编辑

### 切换方式

在结果面板顶部点击「**渲染**」/「**源码**」按钮切换查看模式。

---

## 多文件切换

如果上传了多个文件，结果面板顶部会显示文件标签：

- 点击文件标签切换查看不同文件的分析结果
- 已分析的文件显示文件名
- 未分析的文件显示 `文件名 (未分析)`

---

## 合并结果

当有 **2 个及以上**文件完成分析后，可以合并结果：

1. 点击「**一键合并**」按钮
2. 等待合并完成
3. 合并结果会按文件顺序排列，生成一份完整文档

> 💡 合并顺序与文件列表顺序一致，可通过拖拽调整文件顺序。

---

## 复制内容

点击「**复制**」按钮，将当前结果的 Markdown 源码复制到剪贴板。

### 使用场景

- 粘贴到 Typora、VS Code 等 Markdown 编辑器
- 粘贴到笔记软件（如 Notion、Obsidian）
- 粘贴到 AI 对话中进行二次提问

> ⚠️ 复制的是 Markdown 源码，不是渲染后的文本。如需渲染效果，请粘贴到支持 Markdown 的编辑器中。

---

## 导出文件

点击「**导出**」按钮，将分析结果保存为文件。

### 导出格式

- **Markdown 文件**（`.md`）：保留完整的 Markdown 格式和 LaTeX 公式

### 导出位置

- 文件会保存到系统默认的下载目录
- 文件名格式：`分析结果_文件名.md`

> 💡 如果导出失败，可以使用「复制」功能手动保存内容。

---

## 结果中的图片标签

理工速知和文采丰呈模式的分析结果中，可能包含图片标签：

```
[[IMG_P3_1]]
```

这表示原文第 3 页的第 1 张图片。图片标签的含义：

- `P` 后的数字：页码
- `_` 后的数字：该页的图片序号

> 💡 图片标签是原文图片的占位标记，在 Markdown 渲染中不会显示为实际图片。如需查看原文图片，请参考原始 PDF 文档。

---

## 常见问题

### Q: 分析结果中公式显示异常？

OneDocs 内置的 Markdown 渲染器支持大部分 LaTeX 公式，但某些复杂公式可能渲染不完整。解决方案：

1. 切换到「源码模式」查看原始公式
2. 复制 Markdown 源码到 Typora 等专业编辑器查看
3. 导出为 `.md` 文件后用其他工具打开

### Q: 合并结果顺序不对？

合并顺序与文件列表顺序一致。在上传区域拖拽文件标签可以调整顺序，调整后再点击合并。

### Q: 导出的文件在哪里？

默认保存在系统下载目录中。如需更改保存位置，可在「设置 → 通用 → 数据管理」中修改数据目录。
