# 🖥️ 界面总览

OneDocs 的界面由顶部导航栏和多个功能页面组成，布局简洁直观。

---

## 导航栏

顶部导航栏包含以下标签页：

| 标签 | 功能 |
|------|------|
| **分析** | 主功能页面，上传文档并进行分析 |
| **存档** | 查看历史分析记录 |
| **发现** | 版本更新与发布记录 |
| **关于** | 版本信息、项目简介、功能介绍、帮助教程 |
| **设置** | 模型配置、外观设置、通用设置 |

导航栏右侧还有：
- 🌓 **主题切换**：浅色/深色/跟随系统
- 🌐 **语言切换**：中文/English

---

## 分析页面

分析页面是 OneDocs 的核心功能区域，采用三栏布局：

```
┌──────────────┬─────────────────────┬──────────────────────┐
│  功能选择栏   │     文件上传区       │     结果展示区        │
│  (左侧)      │     (中间)          │     (右侧)           │
│              │                     │                      │
│  · 要闻概览   │  点击选择文档...      │  分析结果将在此展示    │
│  · 罗森析数   │                     │                      │
│  · 理工速知   │                     │                      │
│  · 文采丰呈   │                     │                      │
│              │                     │                      │
│  ──────────  │                     │                      │
│  开始析文     │                     │                      │
└──────────────┴─────────────────────┴──────────────────────┘
```

### 左侧：功能选择栏

- 四种分析模式按钮，点击选择当前分析功能
- 「开始析文」按钮，点击后开始分析

### 中间：文件上传区

- 点击或拖拽上传 PDF 文件
- 显示已上传文件列表
- 支持文件排序（拖拽调整顺序）

### 右侧：结果展示区

- 分析完成后展示结果
- 支持渲染/源码两种查看模式
- 提供复制和导出功能

---

## 设置页面

设置页面分为三个标签：

### 通用

- **语言设置**：切换中文/英文界面
- **分析设置**：格式复查开关、自动保存开关
- **数据管理**：数据目录配置
- **RAG 嵌入模型配置**：SiliconFlow Token 配置
- **开发者模式**（需手动开启）

### 外观

- **主题模式**：浅色/深色/跟随系统
- **字体风格**：选择界面字体
- **字号大小**：调整字体缩放比例
- **背景颜色**：自定义背景色
- **背景图片**：上传自定义背景图

### 模型

- **供应商选择**：选择 AI 模型供应商
- **API Key**：填入对应供应商的 API Key
- **Base URL**：自定义 API 地址（可选）
- **模型选择**：选择具体使用的模型
- **自定义模型**：添加供应商未内置的模型

---

## 存档页面

存档页面采用左右两栏布局：

- **左侧**：历史分析记录列表，显示时间和文件数量
- **右侧**：选中存档的分析结果，支持渲染/源码查看

---

## 发现页面

发现页面展示 OneDocs 的版本更新记录：

- **左侧**：版本列表
- **右侧**：选中版本的更新说明

---

## 关于页面

关于页面包含四个标签：

| 标签 | 内容 |
|------|------|
| **版本** | 当前版本号、官网入口、开源仓库、开源协议、技术栈 |
| **简介** | OneDocs 项目介绍 |
| **功能** | 四大分析模式介绍 |
| **帮助** | 完整的新手使用教程 |
