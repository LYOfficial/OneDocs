# 👋 欢迎使用 OneDocs

**文章千卷，一览而知。智慧之器，助君析文明理。**

OneDocs（一文亦闻）是一款基于 AI 的智能文档分析工具，集诸多智能提示之力，助君速览文档精髓——无论新闻要览、数据解析，抑或学科要点，皆可一键明了。

---

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| 🧠 **四大分析模式** | 要闻概览、罗森析数、理工速知、文采丰呈，覆盖多种文档类型 |
| 🤖 **40+ 模型支持** | OpenAI、智谱 GLM、DeepSeek、Gemini、Ollama 等主流模型 |
| 📄 **PDF 智能解析** | 文本提取 + 图片提取，完整还原文档内容 |
| 🔒 **本地隐私安全** | 所有文档处理均在本地完成，文件不会上传至第三方服务器 |
| 🌍 **跨平台支持** | Windows / macOS / Linux 全平台覆盖 |
| 🌐 **中英双语** | 支持中文和英文界面切换 |
| 📦 **多文件合并** | 支持同时分析多个文件并一键合并结果 |
| 🎨 **个性化外观** | 浅色/深色主题、自定义字体、背景图片 |

---

## 🚀 快速开始

1. **下载安装**：前往 [最新版本](https://github.com/LYOfficial/OneDocs/releases/latest) 下载适合你系统的安装包
2. **启动软件**：安装后启动，点击「始于一文」进入主界面
3. **配置模型**：在「设置 → 模型」中选择 AI 供应商并填入 API Key（也可使用内置免费模型）
4. **上传分析**：上传 PDF 文档，选择分析功能，点击「开始析文」

👉 详细步骤请阅读 [快速开始](Quick-Start)
