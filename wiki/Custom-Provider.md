# 🔧 自定义模型供应商

OneDocs 支持添加自定义模型供应商，兼容所有提供 OpenAI 格式 API 的服务。

---

## 适用场景

- 使用 OneDocs 未内置的 API 服务
- 使用自建的 API 代理/中转服务
- 使用企业内部部署的模型服务
- 使用其他兼容 OpenAI 格式的第三方平台

---

## 添加自定义供应商

### 步骤

1. 进入「**设置**」→「**模型**」
2. 找到「**自定义供应商**」区域
3. 填写以下信息：

| 字段 | 必填 | 说明 |
|------|------|------|
| **名称** | ✅ | 自定义供应商的显示名称 |
| **Base URL** | ✅ | API 服务地址，如 `https://api.example.com/v1` |
| **模型** | ✅ | 模型 ID，如 `my-model-name` |
| **API Key** | ❌ | API 密钥，部分服务不需要 |

4. 点击「**添加**」完成创建

## 兼容平台配置示例

### 优云智算

| 字段 | 值 |
|------|-----|
| 名称 | 优云智算 |
| Base URL | 平台提供的 API 地址 |
| 模型 | 平台支持的模型 ID |
| API Key | 平台提供的 API Key |

### 302.AI

| 字段 | 值 |
|------|-----|
| 名称 | 302.AI |
| Base URL | `https://api.302.ai/v1` |
| 模型 | 平台支持的模型 ID |
| API Key | 302.AI 提供的 API Key |

### 硅基流动

| 字段 | 值 |
|------|-----|
| 名称 | 硅基流动 |
| Base URL | `https://api.siliconflow.cn/v1` |
| 模型 | 如 `Qwen/Qwen2.5-7B-Instruct` |
| API Key | SiliconFlow 提供的 API Key |

### OneAPI / NewAPI

| 字段 | 值 |
|------|-----|
| 名称 | OneAPI |
| Base URL | 你的 OneAPI 服务地址 |
| 模型 | 通过 OneAPI 分发的模型 ID |
| API Key | OneAPI 生成的 Token |

## 管理自定义供应商

### 编辑

1. 在自定义供应商列表中找到要编辑的供应商
2. 修改相关配置
3. 保存更改

### 删除

1. 在自定义供应商列表中找到要删除的供应商
2. 点击删除按钮
3. 确认删除

> ⚠️ 删除供应商后，如果当前正在使用该供应商，会自动切换到 OpenAI。

---

## 添加自定义模型

如果内置的模型列表中没有你需要的模型，可以手动添加：

1. 选择一个供应商
2. 在模型选择区域找到「**自定义模型**」
3. 输入模型 ID（需与 API 供应商支持的模型 ID 一致）
4. 点击添加

---

## 常见问题

### Q: 自定义供应商连接失败？

- 检查 Base URL 是否正确（通常以 `/v1` 结尾）
- 确认 API 服务是否正常运行
- 检查 API Key 是否有效
- 确认网络连接正常

### Q: 模型列表中没有我需要的模型？

使用「自定义模型」功能手动添加模型 ID。模型 ID 需要与 API 供应商支持的完全一致。

### Q: 可以添加多个自定义供应商吗？

可以，没有数量限制。每个自定义供应商可以有独立的名称、Base URL、模型和 API Key。
